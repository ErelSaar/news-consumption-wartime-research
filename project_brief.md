# Project Brief

## Project Name
News Consumption During Wartime in Israel — Research Portfolio Project

## Goal
Build a professional research repository that investigates how news consumption patterns in Israel changed during wartime, especially after October 7, 2023. The project produces clean, analysis-ready outputs that can be embedded into a personal portfolio website.

## Research Question
How did news consumption patterns in Israel change during wartime, and what role did fast-moving platforms like Telegram play compared with search interest and traditional news websites?

## Origin
This project was inspired by a personal Telegram news bot that aggregated breaking news from Israeli public channels. While building and using that bot, a broader question emerged: during a crisis, how do people's information habits actually change, and which platforms do they turn to first?

## Scope
- **Study period:** September 1 – December 31, 2023
- **Key date:** October 7, 2023
- **Platforms:** Telegram, RSS/news websites, Google Trends
- **Geography:** Israel (IL)
- **Language:** English

## What This Project Is
- A research workflow demonstration
- A portfolio artifact showing data collection, analysis, and storytelling skills
- A template for replacing simulated data with real collected data

## What This Project Is Not
- A production data platform
- Real-time monitoring infrastructure
- A tool requiring APIs or cloud services to run
